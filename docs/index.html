sonore

Signals and stimuli for auditory research, built for Jupyter.

sonore is a small Python library for making, manipulating and analyzing sounds the way hearing scientists think about them: tones, harmonic complexes, shaped noises, invertible spectrograms, voices, sound textures, binaural cues, HRIR spatialization and synthetic reverberation. Levels are written as levels (snd + 6*dB), times as seconds (snd[0.1:0.5]), and any sound at the end of a cell plays.

Try it here

Edit the code and press Run (or Ctrl+Enter, ⌘+Enter on a Mac). It runs in your browser through Pyodide: nothing to install, and your code never leaves the page. The first run downloads Python, numpy, scipy, matplotlib and sonore, about 35 MB, and takes around half a minute; later runs take a second or two.

The page first runs the setup cell of the Colab tutorial, so so, dB, np, plt, fs and its show and download are defined, and any of its cells can be pasted here as it is. show plays each sound with its overview below; a sound on the last line gets a player too. The cells that load HRIRs may not work here, since they download from another site.
