sources
=======

Sounds made from parameters alone: tones, noises, chirps and the LF glottal source, Klatt's formant synthesizer, a voice rebuilt from a source-filter description, spectrotemporal ripples, random spectrograms with natural correlations, and trains of copies of one event.
