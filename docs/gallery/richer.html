A richer source-filter model

The source-filter model rebuilt each sentence from a pitch track and a liftered cepstral envelope, and ended on three ways the copy falls short: the envelope runs under the harmonic peaks, voicing is all or nothing, and the phases are chosen rather than measured. This page takes them in that order, and then puts a voice back together from all three.

Each method is built up the same way: what goes wrong without the step, the step in one sentence, its equation with every symbol named, and what it does to one time window. The names are those of sonore's code; a symbol is used only where an equation needs one, and is defined beside it.

The sentence, the vowel, and code the examples share

The sentence both talkers read (What is a voice), with so.f0_track's pitch track and the track WORLD's Harvest (Morise, 2017) measured on each recording, stored with it.

Beside it, a synthetic vowel whose every part is known: the vowel of "hod", made from Klatt's (1980) glottal source, the radiation from the lips and five formants, as A vowel, piece by piece explains; the code is repeated here so that the page runs on its own. The source is a sum of harmonics at a steady pitch, the median pitch of each talker's recording, plus, for the second section, white noise. At the male talker's pitch the vowel has Peterson and Barney's (1952) male formants for "hod", and at the female talker's pitch their female ones (Six vowels). Since the source and the filter are known, so are the vowel's true envelope and its true aperiodicity.

def fetch(path):
    """A file from the sonore repository, by its path there: the local copy when this runs from
    the repository root, otherwise downloaded from GitHub to the same relative path."""
    if not os.path.exists(path):
        os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
        urllib.request.urlretrieve("https://raw.githubusercontent.com/choyun1/sonore/main/" + path, path)
    return path


def finish(snd):
    """How every sound in the gallery is played: 5 ms ramps, RMS 0.1, peak at most 0.95."""
    snd = snd.ramp(5e-3).normalize(rms=0.1)
    return snd.normalize(peak=0.95) if snd.peak > 0.95 else snd

def formants(snd, table):
    for freq, bandwidth in table:
        snd = so.resonator(snd, freq, bandwidth)
    return snd


# Klatt's glottal source and the radiation from the lips, and the formants, as gains at any
# frequency: the spectra of their impulse responses.
impulse = so.Sound(np.r_[1.0, np.zeros(2**14 - 1)], FS)
glottal_gain = np.abs(np.fft.rfft(so.resonator(impulse, 0, 100).data[:, 0]))
gain_freqs = np.fft.rfftfreq(2**14, 1 / FS)
tract_gains = {
    label: np.abs(np.fft.rfft(formants(impulse, table).data[:, 0])) for label, table in HOD.items()
}


def source_gain(f):
    return np.interp(f, gain_freqs, glottal_gain) * np.abs(2 * np.sin(np.pi * np.asarray(f) / FS))


def true_envelope_db(f, label):
    """The vowel's envelope in dB, up to a constant: source times radiation times formants."""
    return 20 * np.log10(source_gain(f) * np.interp(f, gain_freqs, tract_gains[label]) + 1e-12)


def breathy_source(f0):
    """Harmonics of f0 with Klatt's source spectrum, up to 7.2 kHz, and white noise with the
    harmonics' power per hertz at 4 kHz."""
    harmonic_numbers = np.arange(1, int(0.45 * FS / f0) + 1)
    buzz = so.harmonic_complex(
        DUR, FS, f0, harmonics=harmonic_numbers, amplitudes=lambda t, f: source_gain(f)
    )
    # harmonic_complex scales its output to RMS 1; the harmonics' power per hertz near f is then
    # (scale * gain(f))^2 / 2 per harmonic, one harmonic every f0 hertz
    scale = 1 / np.sqrt(np.sum(source_gain(harmonic_numbers * f0) ** 2) / 2)
    noise_density = (scale * source_gain(4000.0)) ** 2 / 2 / f0
    hiss = so.gaussian_noise(DUR, FS, rng=1) * np.sqrt(noise_density * FS / 2)  # white: flat density
    return buzz, hiss


def true_aperiodicity(f):
    """The share of noise at f, from the source alone. With the noise as strong as the harmonics
    at 4 kHz it is the same at any pitch."""
    return 1 / (1 + (source_gain(f) / source_gain(4000.0)) ** 2)

An envelope measured to the pitch period

The spectral envelope is the smooth curve the vocal tract lays over the harmonics. Measured from one time window, it has to come from a spectrum that is not smooth: the harmonics of a voiced sound sample the envelope only every F_0 hertz. Every method below starts from the power spectrum of the sound under a window w, centered at time t and scaled to unit energy so that its level does not depend on the window's length,

P(t, f) = \frac{\bigl|\sum_n w(n - t f_s)\, x(n)\, e^{-2\pi i f n / f_s}\bigr|^2}{\sum_n w(n)^2},

with x(n) the sound's samples and f_s the sampling rate.

A fixed window ripples

For a periodic sound no window length gives a smooth envelope. A window shorter than a period smears the harmonics together, so the spectrum is smooth across frequency; but the window then holds a different part of the period at each position, and the power at every frequency rises and falls with period 1/F_0 as the window slides. A window several periods long holds the same amount of the sound wherever it is, so the power is steady over time; but it resolves the harmonics, and the spectrum ripples across frequency, high at each harmonic and low between. The cell measures both on the vowel's buzz alone (harmonics, no noise) at each talker's pitch, for Hann windows of one to six periods: across frequency, the standard deviation of the spectrum's distance from the true envelope from 200 Hz to 4 kHz; over time, the standard deviation of each frequency's level as the window slides over one period, the median over frequencies.

Code
N_FFT = 1024
spectrum_freqs = np.fft.rfftfreq(N_FFT, 1 / FS)
band = (spectrum_freqs > 200) & (spectrum_freqs < 4000)


def hann_power(samples, center, length, shape="hann"):
    """P(t, f) at sample `center` under a window `length` samples long (may be fractional): Hann,
    or Blackman, scaled to unit energy."""
    offsets = np.arange(-int(np.ceil(length / 2)), int(np.ceil(length / 2)) + 1)
    phase = 2 * np.pi * offsets / length
    weights = (
        0.5 + 0.5 * np.cos(phase)
        if shape == "hann"
        else 0.42 + 0.5 * np.cos(phase) + 0.08 * np.cos(2 * phase)
    )
    weights[np.abs(offsets) >= length / 2] = 0
    segment = samples[int(round(center)) + offsets] * weights
    return np.abs(np.fft.rfft(segment / np.sqrt(np.sum(weights**2)), N_FFT)) ** 2


def ripples(label, periods, shape="hann", pair=False):
    """The ripple across frequency and over time (dB) of windows `periods` long, over 16
    positions within one period at 0.5 s; with `pair`, each position's power is TANDEM's
    average of two windows a quarter period before and after it."""
    samples, period = buzz_vowels[label].data[:, 0], FS / medians[label]
    levels = []
    for step in range(16):
        center = 0.5 * FS + step / 16 * period
        if pair:
            power = (
                hann_power(samples, center - period / 4, periods * period, shape)
                + hann_power(samples, center + period / 4, periods * period, shape)
            ) / 2
        else:
            power = hann_power(samples, center, periods * period, shape)
        levels.append(10 * np.log10(power + 1e-12))
    levels = np.array(levels)
    truth = true_envelope_db(spectrum_freqs, label)
    across = np.median([np.std((level - truth)[band]) for level in levels])
    over_time = np.median(np.std(levels[:, band], axis=0))
    return levels, across, over_time

No length does well on both. The flicker over time falls from several decibels at one period to a tenth of a decibel at three, while the spectrum departs from the envelope across frequency as the harmonics are resolved, by about 16 dB at six periods. The one-period window departs from it as well, because it smears the formants. The pitch-adaptive methods do not look for a compromise length; each one removes one of the two ripples by construction and then smooths the other away.

STRAIGHT

STRAIGHT (Kawahara, Masuda-Katsuse & de Cheveigné, 1999) was the first to tie the analysis to the pitch. Its window is a Gaussian whose width is a fixed multiple of the period T_0 = 1/F_0, so that the harmonics are separated equally well at every pitch. The ripple across frequency is then smoothed in frequency, with a triangular kernel as wide as the harmonic spacing F_0, which interpolates between the harmonic peaks rather than averaging them with the dips. The ripple over time is filled by a second, complementary window, the first one multiplied by \sin(\pi t / T_0), whose power peaks where the first one's dips; the two powers P and P_c are combined as

P_{\text{STRAIGHT}}(t, f) = \sqrt{P(t, f)^2 + \xi\, P_c(t, f)^2},

with \xi a constant the paper chose to leave the least fluctuation. sonore has no STRAIGHT code; this section only describes it.

TANDEM-STRAIGHT

TANDEM-STRAIGHT (Kawahara et al., 2011) removes the ripple over time more simply. The flicker of a window's power repeats once a period, so at two positions half a period apart its fundamental is in opposite phase, and their average cancels it:

P_{\text{TANDEM}}(t, f) = \tfrac12\bigl(P(t - T_0/4, f) + P(t + T_0/4, f)\bigr),

with Blackman windows 2.5 periods long. Seeing speech draws this power spectrogram, as so.tandem_power. The cell measures the flicker of one Blackman window and of TANDEM's pair, on the same buzz.

CheapTrick, step by step

CheapTrick (Morise, 2015), so.pitch_adaptive_envelope in sonore, keeps TANDEM's idea of a window steady over time, in its simplest form, and replaces STRAIGHT's smoothing by three short steps.

1. The window. A Hann window three periods long: as the table above shows, its power hardly changes with its position in the period, so no second window is needed. 2. The smoothing. A moving average across frequency over 2F_0/3,

P_s(f) = \frac{3}{2F_0} \int_{-F_0/3}^{F_0/3} P(f + \nu)\, d\nu,

which fills the dips between harmonics, so that the logarithm can be taken, without yet removing the ripple. 3. The lifter. The cepstrum c(\tau) of \log P_s, at quefrencies \tau in seconds, is multiplied by two lifters and transformed back:

E(f) = \exp\Bigl(\mathcal{F}\bigl[\,l_s(\tau)\, l_r(\tau)\, c(\tau)\,\bigr]\Bigr), \qquad l_s(\tau) = \frac{\sin(\pi F_0 \tau)}{\pi F_0 \tau}, \qquad l_r(\tau) = (1 - 2q_1) + 2q_1 \cos(2\pi F_0 \tau).

The smoothing lifter l_s is a moving average over one harmonic spacing, which removes the ripple at F_0. The recovery lifter l_r gives back the sharpness that the two moving averages took from the envelope's peaks; q1 sets how much, and the paper's value is -0.09.

The cell writes the three steps out with NumPy at one time window of the female talker's buzz, and compares the result with so.pitch_adaptive_envelope.

Code
label = "Female talker"
F0, samples = medians[label], buzz_vowels[label].data[:, 0]
power = hann_power(samples, 0.5 * FS, 3 * FS / F0)  # step 1

# step 2: the moving average over 2 F0 / 3, on a grid eight times finer than the FFT's, with the
# spectrum mirrored about 0 Hz and Nyquist, as a real signal's spectrum continues there
mirrored = np.concatenate([power[:0:-1], power, power[-2::-1]])
fine = np.interp(np.arange(0, len(mirrored) - 1, 1 / 8), np.arange(len(mirrored)), mirrored)
half_width = int(round(F0 / 3 / (FS / N_FFT) * 8))
fine_smoothed = np.convolve(fine, np.ones(2 * half_width + 1) / (2 * half_width + 1), mode="same")
smoothed = fine_smoothed[::8][len(power) - 1 : 2 * len(power) - 1]

# step 3: the cepstrum of the log power, the two lifters, and back
cepstrum = np.fft.irfft(np.log(smoothed), N_FFT)
quefrency = np.minimum(np.arange(N_FFT), N_FFT - np.arange(N_FFT)) / FS


def liftered(q1):
    lifters = np.sinc(F0 * quefrency) * ((1 - 2 * q1) + 2 * q1 * np.cos(2 * np.pi * F0 * quefrency))
    return np.exp(np.fft.rfft(lifters * cepstrum, N_FFT).real)

Against the lifter, on a recording

On the recordings there is no true envelope, but CheapTrick can be set beside the cepstral lifter of One time window. A source that is partly noise

In the first-order source-filter picture a voice's source is either a buzz (voiced) or a hiss (unvoiced). A vocoder such as WORLD (Morise, Yokomori & Ozawa, 2016) keeps three things instead of two: the pitch, a smooth spectral envelope, and an aperiodicity. The aperiodicity replaces the voicing switch. At every frequency it says what share of the power is noise rather than harmonics,

A(f) = \frac{N(f)}{N(f) + P(f)},

with N the power of the noise and P that of the harmonics at f. The buzz is A = 0 everywhere and the hiss is A = 1; a voice is in between, and usually more so at high frequencies, so it can be clearly periodic at 500 Hz and mostly noise at 5 kHz. The vowel's harmonics fall about 6 dB per octave and its noise is flat, so its share of noise rises about 6 dB per octave; the noise is set as strong as the harmonics at 4 kHz.

Fit the harmonics, keep the rest

The definition suggests the measurement: find the best periodic sound, take it away, and see how much is left. If the pitch is known, the periodic part of a short stretch is a sum of harmonics whose phases follow the running phase \Phi(t) = 2\pi \int F_0, each with an amplitude and a phase to be found. That is a linear least-squares fit. Here is one time window of the vowel at the male talker's pitch, under a Hann window four periods long, with each harmonic also allowed an amplitude that changes linearly across the window.

Code
vowel, F0 = vowels["Male talker"], medians["Male talker"]
center = int(0.5 * FS)  # the time window at 0.5 s
half = int(round(2 * FS / F0))  # half of four periods
offsets = np.arange(-half, half + 1)
fit_window = 0.5 + 0.5 * np.cos(np.pi * offsets / (half + 1))
phase = 2 * np.pi * F0 * offsets / FS  # the running phase over the time window
harmonic_phases = np.outer(phase, np.arange(1, int(FS / 2 / F0) + 1))
ramp = (offsets / half)[:, None]
columns = np.column_stack(
    [np.ones(len(offsets)), np.cos(harmonic_phases), np.sin(harmonic_phases)]
    + [ramp * np.cos(harmonic_phases), ramp * np.sin(harmonic_phases)]
)
segment = vowel.data[center + offsets, 0]
root_window = np.sqrt(fit_window)  # weighted least squares: minimize the windowed residual
weights, *_ = np.linalg.lstsq(columns * root_window[:, None], segment * root_window, rcond=None)
residual = segment - columns @ weights
print(f"{columns.shape[1]} columns fitted to {len(offsets)} samples")
residual_power, signal_power = np.sum((fit_window * residual) ** 2), np.sum((fit_window * segment) ** 2)
print(f"windowed residual power over windowed signal power: {residual_power / signal_power:.3f}")

The measure is the definition, which makes it easy to explain and to check. It has one weakness: it needs the pitch to about a tenth of a percent. A harmonic whose frequency is slightly wrong drifts out of phase with the fit over the window, and what the fit misses reads as noise, more so the higher the harmonic. For the same reason it reads cycle-to-cycle irregularity (jitter and shimmer) as noise.

What D4C reports

WORLD's own measure is D4C (Morise, 2016); so.band_aperiodicity is written from its paper. It works from a "group delay" of the time window, smoothed over the harmonics, whose spectrum is sorted to see how much of its power lies outside the strongest components, in bands 6 kHz wide around each multiple of 3 kHz. The curve is drawn as straight lines (in dB) from −60 dB at 0 Hz through the bands' values, held flat above the last band. At 16 kHz there is only one band, at 3 kHz. D4C's paper says it was tuned with listening tests so that WORLD's resynthesis sounds natural; the −60 dB at 0 Hz says "the lowest frequencies are periodic", which is usually true of speech.

Phases on a moving pitch

The envelope and the aperiodicity fix the spectrum, but the starting phases decide the waveform, and no view on this page keeps them. In cosine phase all the harmonics peak together once a period, giving a sharp pulse; Schroeder's phases spread the energy across the period for a nearly flat envelope (Schroeder, 1970); random phases fall in between. With a contour the phases set only where each harmonic starts. After that every harmonic runs at exactly n times the same instantaneous frequency, so the waveform keeps its shape as the pitch moves. The examples use harmonics of equal amplitude on each talker's so.f0_track, to show the phases alone.

Putting it back

so.source_filter_synthesize puts a voice back together from the three views as two parts added. With the envelope S(t, f) (power per hertz), the aperiodicity A(t, f) and the pitch track F_0(t):

  • Harmonics on the pitch track, \sum_n a_n \cos\bigl(n\,\Phi(t)\bigr), carrying the harmonics' share of the envelope, S(1 - A). Harmonic n stands for one harmonic spacing, F_0 hertz, of that power, so its amplitude is

\frac{a_n^2}{2} = \frac{2 F_0}{f_s} S(1 - A) \text{ at } f = n F_0,

with f_s the sampling rate (the 2/f_s converts the envelope's one-sided power per FFT bin to power per hertz). - Noise: white noise whose STFT magnitude is multiplied by \sqrt{S A}, and by \sqrt{S} where the track says unvoiced, then inverted.

Against the simple rebuild

Putting it back, simply rebuilt each sentence from so.f0_track's track and the liftered cepstral envelope, with no aperiodicity, and its noise came out too loud against its voiced stretches. The cell rebuilds each sentence from the same track four ways: that simple rebuild, CheapTrick's envelope with no aperiodicity, and CheapTrick's envelope with each aperiodicity. It prints, for each, the unvoiced stretches' level relative to the voiced ones, against the recording's, and the distance from the recording: the level-free RMS difference in dB between their 40-band log mel spectrograms, the median over the voiced time windows and over the unvoiced ones.

Code
def liftered_envelope(snd, track):
    """The cepstrum of 40 ms Hann time windows every 5 ms, liftered below half the pitch period
    of each window (the track's voiced F0, interpolated on a log scale across unvoiced gaps)."""
    cepstrum = so.Cepstrum(so.STFT(snd, win_dur=0.040, hop_dur=0.005))
    is_voiced = track.voiced[0]
    periods = 1 / np.exp(np.interp(cepstrum.t, track.t[is_voiced], np.log(track.f0[0][is_voiced])))
    return cepstrum.lifter(0.5 * periods).envelope_view()


def unvoiced_re_voiced(snd, track):
    """The RMS of a sound's unvoiced stretches over that of its voiced ones, in dB."""
    samples = snd.data[:, 0]
    voiced = np.interp(np.arange(len(samples)) / snd.fs, track.t, track.voiced[0].astype(float))
    return 20 * np.log10(np.sqrt(np.mean(((1 - voiced) * samples) ** 2) / np.mean((voiced * samples) ** 2)))


def distances(snd, label):
    """The level-free RMS dB between the log mel spectrograms of snd and the talker's recording,
    the median over the recording's voiced and over its unvoiced time windows."""
    original, rebuilt = so.MFCC(talkers[label], n_mels=40), so.MFCC(snd, n_mels=40)
    count = min(original.mel_db.shape[2], rebuilt.mel_db.shape[2])
    difference = rebuilt.mel_db[0][:, :count] - original.mel_db[0][:, :count]
    per_window = np.sqrt(np.mean((difference - difference.mean(axis=0)) ** 2, axis=0))
    voiced = np.interp(original.t[:count], tracks[label].t, tracks[label].voiced[0].astype(float)) > 0.5
    return np.median(per_window[voiced]), np.median(per_window[~voiced])

What learned vocoders do

Most neural vocoders, WaveNet (van den Oord et al., 2016) and HiFi-GAN (Kong, Kim & Bae, 2020) among them, do not split source from filter at all: they map a mel spectrogram to a waveform, judged by how it sounds, so they make up plausible phase and fine detail rather than recover them. Those that do split keep this page's structure and learn the rest. LPCNet (Valin & Skoglund, 2019) keeps linear prediction for the filter; neural source-filter models (Wang, Takaki & Yamagishi, 2020) start from a sine source at F_0; DDSP (Engel et al., 2020) is harmonics plus filtered noise, close to the recipe above, with a network choosing the amplitudes and filters. What settles the ambiguity of splitting a sound into a source and a filter (The source-filter model) is, for them, a prior learned from many hours of speech, where the methods on this page have a few fixed constants (q1, the window of three periods, D4C's tuning). The methods on this page show the parts that the learned ones hide.

What this page leaves out

  • STRAIGHT's code. STRAIGHT and TANDEM-STRAIGHT's own smoothing and aperiodicity are described, not implemented; so.tandem_power is only TANDEM's averaged power spectrum.
  • WORLD's pitch tracker. Harvest is not part of sonore; its tracks are stored with the recordings. so.f0_track gives tracks of its own (Measuring the source: pitch).
  • Measured phase. The views keep no phase, so the rebuilt voice's waveform is not the recording's; a minimum-phase or measured pulse shape is not provided.
  • Jitter and shimmer. A pitch track smoothed over 5 ms time windows cannot follow cycle-to-cycle irregularity, so the harmonic residual counts it as noise, and a resynthesis can only carry it as noise.
